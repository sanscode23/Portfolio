# Sanskar Wankhede | Portfolio Website

A personal portfolio website showcasing my projects, tech stack and contact links. Built from scratch with plain HTML, CSS and JavaScript, with no frameworks, so every part of it is something I wrote and understand.

**Live site:** [add your Vercel link here](https://your-site-link)

## Features

- **Animated intro:** my cartoon portrait looks up from the dark and greets visitors with "Welcome". It plays once per session and can be skipped.
- **Dark neon theme:** glowing buttons, glassy cards and a gradient name heading.
- **Typing effect** that cycles through my roles in the hero section.
- **Scroll animations:** sections and tech cards reveal themselves as you scroll, using the Intersection Observer API.
- **Sticky navbar** with smooth scrolling and a mobile hamburger menu.
- **Tech stack and project sections** with tags and links to live demos and GitHub.
- **Responsive design** that works on phones, tablets and desktops.
- **Back-to-top button**, resume download and social links.

## Tech Stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox, keyframe animations)
- JavaScript (DOM manipulation, Intersection Observer)
